### 👨‍🍳 → 👨‍💻 The story so far

I used to spend my early mornings behind the counter of a pâtisserie, laminating croissant dough and making desserts before sunrise. These days it's segfaults and 3am debugging sessions at **42** — turns out precision, patience, and a steady hand translate pretty well from pastry to code.

```txt
if (life.job == "pastry_chef") {
    life.job = "software_engineer";  // no regrets, just less butter
}
```
